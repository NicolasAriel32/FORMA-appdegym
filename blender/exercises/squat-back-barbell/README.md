# Sentadilla trasera con barra — fuente 3D

Este directorio reserva la fuente editable del ejercicio patrón:

```text
squat-back-barbell.blend
```

El archivo `.blend` todavía no está disponible dentro del entorno de Codex. Los recursos publicados en `apps/web/public/media/exercises/squat-back-barbell/` son un piloto visual generado para validar la interfaz, el encuadre responsive, el mapa muscular y el análisis técnico.

Cuando se incorpore la fuente de Blender, debe conservar:

- un rig reutilizable;
- cámaras de tres cuartos y lateral;
- marcadores de cadera, rodilla y tobillo;
- trayectoria de barra parametrizada;
- materiales separados para músculos principales y secundarios;
- keyframes de inicio, descenso, fondo controlado y regreso;
- exportación web optimizada y reproducible;
- revisión profesional antes de cambiar `status` a `approved` en `metadata.json`.
